Notes

  • Polish letters are separate letters: ą is never revealed by guessing a. That is how the desktop version behaves, so the on-screen keyboard gains a row of ą ć ę ł ń ó ś ź ż while the Polish dictionary is active.
  • The state is written after every key press — reload the page, lock the phone, come back, and the word, letters, stage and score are where you left them.
  • The dictionaries are the unmodified upstream files (82 155 Polish / 272 372 English lines; 81 835 / 272 371 playable after the original 5–18-character filter).
  • Opening index.html directly works; serving the folder over http(s) just lets the page read the .txt files instead of their generated .js twins.

The pattern is the word as it currently stands; wrong letters are excluded — the same query as F10 and list_words.py.
